# 4: Deep Learning for CV

## Introduction
Explore neural networks for advanced CV tasks like classification and recognition.

## Topics Covered
- Convolutional Neural Networks (CNNs)
- Transfer learning with pre-trained models (e.g., ResNet)
- Fine-tuning for custom datasets

## Quick Start
1. Install: `pip install tensorflow keras opencv-python`.
2. Use the notebook to train a simple classifier.
3. Load and test models.
