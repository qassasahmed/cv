# Computer Vision Lab

## Overall Idea
This repository serves as a hands-on lab for intermediate computer vision (CV) students. Assuming familiarity with basics like image loading and filtering, it guides learners through applied techniques, from object detection to deep learning projects. The focus is on practical implementation using Python libraries like OpenCV and TensorFlow, with Jupyter notebooks for experimentation. Each phase builds on the previous, culminating in integrated projects that demonstrate real-world CV applications.

## Project Phases
The lab is structured into 5 progressive phases, each in its own folder:

1. **Recap and Applied Basics**: Review core concepts and apply them to image enhancement tasks.
2. **Object Detection**: Explore traditional (e.g., Haar cascades) and modern (e.g., YOLO) methods for detecting objects in images/videos.
3. **Image Segmentation**: Learn to partition images into regions using thresholding, contours, and neural networks like U-Net.
4. **Deep Learning for CV**: Dive into CNNs, transfer learning, and fine-tuning models for classification and recognition.
5. **Projects and Integration**: Build end-to-end projects combining multiple techniques, with considerations for ethics and optimization.

## Getting Started
- Clone the repo and navigate to cv folder.
- Install dependencies: `pip install -r requirements.txt`.
- Open notebooks in Jupyter or VS Code for interactive coding.
- Prerequisites: Python basics and introductory CV knowledge.
