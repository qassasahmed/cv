# 2: Object Detection

## Introduction
Dive into detecting objects in images and videos using traditional and modern methods.

## Topics Covered
- Haar cascades for face detection
- Introduction to deep learning-based detection (e.g., SSD, YOLO basics)
- Evaluating detection accuracy

## Quick Start
1. Install additional libraries: `pip install opencv-python tensorflow`.
2. Use the notebook with sample images/videos.
3. Test on your own data.

## Prerequisites
Basics from PARTONE.

## Tools and Online Examples
- [OpenCV Haar Cascades](https://docs.opencv.org/3.4/db/d28/tutorial_cascade_classifier.html): Tutorial on face detection.
- [YOLO GitHub](https://github.com/ultralytics/yolov5): Repository for YOLO object detection.
- [TensorFlow Object Detection API](https://tensorflow-object-detection-api-tutorial.readthedocs.io/en/latest/): Guide for SSD and other models.
