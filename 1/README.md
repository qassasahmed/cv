# 1: Recap and Applied Basics

## Introduction
This part recaps basic CV concepts (e.g., image loading, filters) and applies them to simple tasks like image enhancement.

## Topics Covered
- Reviewing pixel operations and color spaces
- Advanced filtering (e.g., morphological operations)
- Basic image transformations (e.g., rotation, scaling)

## Quick Start
1. Install libraries: `pip install opencv-python numpy matplotlib`.
2. Run the notebook to experiment with sample images.
3. Modify code for custom effects.

## Prerequisites
Familiarity with Python and basic CV (e.g., from beginner tutorials).
